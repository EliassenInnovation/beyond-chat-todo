How to use this example

Read a conversation and its actions, then decide whether the issue is in the application, the grader, or both. The original flag and assistant note are collapsed so you can form your own view first. These selected examples are a discussion queue, not a representative accuracy sample.

For ordinary changes: offline tests → focused evals → a full regression run when model behavior can change. Twenty full runs establish variation; they are not required after every edit. A new prompt, model, tool or grader starts a reviewed comparison period, not automatically new control limits.
